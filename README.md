# Comms Interface

A C++ based communication interface for managing camera operations.

## Current Stage

Initial project setup.

## Planned Architecture

- API / command handling
- Command validation
- Command queue
- Worker pool
- Dispatcher
- ONVIF camera communication
- Event handling
- Database / camera registry
- Authentication and authorization
- Testing and logging

## Development Environment

- C++
- GCC
- CMake
- Git
- VS Code

## Project Goal

Build the Comms Interface incrementally and understand each component,
its responsibilities, and its interaction with the rest of the system.
